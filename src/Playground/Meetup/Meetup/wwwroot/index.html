Meetup GraphQL examples

Plan a user-group talk, register attendees, and watch changes arrive through the event stream.

Open the GraphQL playground →

Copy an operation below into the playground and run it. Start by creating a talk, then use its returned ID to register an attendee.

1. Create a talk

The response includes the talk ID. Save it for the registration operation.

mutation AddTalk {
  newUserGroupTalk(title: "Event sourcing in 20 minutes", maxAttendees: 5) {
    id
    title
  }
}

2. List talks and attendees

query GetTalks {
  talks {
    id
    title
    maxAttendees
    talkPublished
    attendees {
      name
      isOnWaitList
    }
  }
}

3. Register an attendee

Replace YOUR_TALK_ID with the ID returned when you created the talk. Once the talk is full, new attendees join the waitlist.

mutation RegisterAttendee {
  registerParticipant(
    talkId: "YOUR_TALK_ID"
    name: "Alex"
    mailAddress: "alex@example.com"
  )
}

4. Watch changes live

Run this subscription in a second playground tab, then create a talk or register another attendee in the first tab.

subscription WatchTalks {
  onTalkChanged {
    changeInfo
    talk {
      id
      title
      attendees {
        name
        isOnWaitList
      }
    }
  }
}
